# Fault Tolerant Airline Reservation and Notification System

![Status](https://img.shields.io/badge/Status-In%20Development-yellow)

A distributed, fault-tolerant Go backend system for an airline engineered to manage high-concurrency booking transactions and orchestrate timed, event-driven user notifications, utilizing PostgreSQL and Redis. Currently in active development.

## Technology Stack

* **Backend:** Go (Golang)
* **Database:** PostgreSQL
* **Data Storage and Caching:** Redis
